# Solution Archive & Template Synthesized Implementations

This directory holds algorithmic solutions developed for problems stored in [`Output/problems/`](../problems/).

---

## 📐 Solution Protocol

All solutions placed in this directory must strictly comply with the **Mandatory Template Output Layer**:

1. **Explicit Template Grounding**:
   - Every solution must declare the matching template used from [`Templates/`](../../Templates/) (e.g., [`Templates/Repetitive Structure Template.md`](../../Templates/Repetitive%20Structure%20Template.md)).

2. **Step-by-Step Derivation**:
   - Solutions must NOT jump straight to code.
   - They must trace through all phases required by the designated template:
     - **Phase 1: Candidate Variable Inventory & Role Assignment** (Free, Carried, Derived, Fixed).
     - **Phase 2: Minimal State Definition & State-Space Tree Construction**.
     - **Phase 3: State Transitions, Invariants & Progress Guarantees**.
     - **Phase 4: Robust Implementation & Failure Mode Auditing** (Edge cases, boundary values, integer overflow).

3. **Multi-Language Reference Implementations**:
   - Provide clean, verified, side-by-side implementations in **Python 3** and **Java 21** (or C++20 where performance benchmarks demand).
