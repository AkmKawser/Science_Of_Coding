# Put The File Here

Place source files here:
- Source PDF documents or book excerpts
- Problem statement text or images
- Supplemental files

### 🔄 Ingestion & Cleanup Process:
1. When you place a file here, the agent reads and extracts the problem statements and metadata.
2. The agent formats the problem following [`problem formatting.md`](../problem%20formatting.md) and records it in [`question bank.md`](../question%20bank.md).
3. Once the problem is completely copied into `question bank.md`, the file in this folder will be cleaned up/removed as requested.
