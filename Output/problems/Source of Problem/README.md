# Source of Problem Directory

This dedicated folder houses all incoming problem inputs before they are parsed, structured, and archived.

---

## 📂 Contents

```
Source of Problem/
├── write here.docx           # Paste problem links, web URLs, and copied text here
└── put the file here/        # Drop source PDF books, chapters, and problem files here
```

---

## 🔄 Ingestion & Cleanup Process
1. **Input**: Add your source links/text in `write here.docx` or upload documents into `put the file here/`.
2. **Parsing**: The agent extracts the problem statement, constraints, and test cases.
3. **Storage**: The agent formats the problem according to [`../problem formatting.md`](../problem%20formatting.md) and adds it to [`../question bank.md`](../question%20bank.md).
4. **Cleanup**: Once copied and formatted, `write here.docx` is reset and the processed file in `put the file here/` is removed.
