# Problem P-1: Series Summation: 1 + 2 + 3 + 4 + .............

## 📌 Metadata & Source Attribution
- **Problem ID**: P-1
- **Problem Title**: Series Summation: 1 + 2 + 3 + 4 + .............
- **Primary Category**: Repetitive Structures
- **Subcategory**: Pattern Printing
- **Source**: Recursion Vs Iteration Complete Codes (Offline Companion)
- **Source Link / Reference**: `Recursion Vs Iteration, Part 1 (Series #1)`
- **Difficulty**: Easy
- **Target Template**: [`Templates/Repetitive Structure Template.md`](../../../Skills_Input/Templates/Repetitive%20Structure%20Template.md)

---

## 📝 Problem Statement
Given a positive integer $N$, generate the mathematical sequence of terms up to the $N$-th term and compute the final cumulative sum:

$$\text{Series: } 1 + 2 + 3 + 4 + ............. $$

Construct each term deterministically using its loop index $i$, display the generated sequence separated by spaces, and compute the total sum.

---

## 📥 Input Specification
- A single integer $N$ ($1 \le N \le 10^4$) representing the number of terms.

---

## 📤 Output Specification
- First line: The generated terms of the series from $1$ to $N$, separated by a space.
- Second line: The total sum formatted as `Sum = <value>`.

---

## 🧪 Sample Tests

### Sample 1
#### Input
```
5
```

#### Output
```
Iteration / Sequence:
[First 5 terms displayed]
Sum = [Total sum]
```

---

## ⚙️ Constraints & System Limits
- Time Limit: 1.0s
- Memory Limit: 256 MB
- Constraints: $1 \le N \le 10^4$
